# GerüstOffice – Installationsdateien und Updates

Hier liegen die Installationsprogramme von **GerüstOffice**, dem Rechnungsprogramm für Gerüstbaubetriebe.

- **Neueste Version herunterladen:** [GeruestOffice-Setup.exe](https://github.com/micha161071-dot/Geruestoffice-updates/releases/latest/download/GeruestOffice-Setup.exe) (immer die aktuelle Version).
- **Benutzen** lässt sich das Programm nur mit einem Freischaltcode. Codes und Testzugänge gibt es bei Michael Kniess, info@kniess.info, Tel. 0171 1238866.
- **Updates** holt sich ein installiertes GerüstOffice von hier selbst. Jede Version wird mit einer signierten Beschreibung (`latest.json`) veröffentlicht. Das Programm installiert nur Dateien, deren Signatur und Prüfsumme stimmen.

Der Quellcode liegt nicht in diesem Archiv.
